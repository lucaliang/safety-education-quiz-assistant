# 使用教程

## 1. 适用范围

本 Skill 面向已获桂林电子科技大学安全教育平台授权的个人用户。它通过 OpenCLI 操作你已授权的 Chrome 浏览器，使用本地题库完成模拟考试或在线考试。

使用前请确认学校允许相应操作。不要共享账号、密码、Cookie、证书或个人考试记录。

## 2. 环境安装

需要：

- Codex CLI；
- Python 3.10 或更高版本；
- Node.js 20 或更高版本；
- [OpenCLI](https://github.com/jackwener/OpenCLI)；
- 已安装 OpenCLI Browser Bridge 扩展并保持连接的 Chrome。

安装完成后运行：

```bash
opencli doctor
python3 scripts/take_online_exam.py preflight
```

两项检查均应通过。若 OpenCLI 显示 Chrome 或扩展未连接，请在安装扩展的 Chrome Profile 中打开任意网页并确认扩展已启用。

## 3. 安装 Skill

将本目录复制到 Codex 可发现的 Skill 路径，或把它作为个人仓库中的本地 Skill 使用。目录至少应保留：

```text
SKILL.md
agents/openai.yaml
scripts/
data/
```

在 Codex 中使用类似指令：

```text
使用 $safety-education-quiz-assistant 完成安全教育在线考试。
```

## 4. 自动在线考试流程

1. Skill 首先运行环境预检。
2. 通过 OpenCLI 打开安全教育平台并点击“打开安全大门”。
3. Skill 询问身份证号、密码及是否记住账号。密码留空时，只在内存中使用身份证后六位。
4. 自动选择“考试”→“在线考试”→“开始考试”。
5. 按题干和完整选项文本匹配四个本地题库并答题。
6. 第 100 题后交卷，只有 100 分才报告通过。
7. 自动进入“查看我的证书”并点击“保存到手机”，等待 PDF 下载完成。

手动运行入口：

```bash
python3 scripts/take_online_exam.py take --login
```

不要将身份证号或密码作为命令行参数传入，也不要把它们写入脚本、环境变量或 Git。

## 5. 未匹配题目

脚本遇到本地题库未命中的题目会暂停，并在 `data/exam-runs/` 写入题干和选项。调用 Skill 的 Agent 应根据可靠的安全知识或权威来源给出答案与依据，然后使用同一记录恢复。

恢复格式：

```bash
python3 scripts/take_online_exam.py take \
  --record data/exam-runs/online-exam-YYYYMMDD-HHMMSS.json \
  --unmatched-answer '["A、完整选项文本"]' \
  --unmatched-evidence '依据：相关法律/安全规范/平台权威说明'
```

不要随机猜题。在线考试必须达到 100 分才视为成功。

## 6. 证书与运行记录

Chrome 默认将 PDF 下载到系统下载目录，通常为：

```text
~/Downloads/
```

运行记录保存于 `data/exam-runs/`，包含题目匹配来源、考试成绩和证书下载结果，不应包含密码或 Cookie。该目录已被 `.gitignore` 排除。

## 7. 常见故障

### OpenCLI 显示 `about:blank`

先执行 `opencli browser safety-education tab list`。确认目标安全教育页面位于安装 Browser Bridge 的同一 Chrome Profile；必要时在该标签页前台聚焦后重新绑定。不要在 `about:blank` 状态下盲目点击或输入。

### 页面按钮找不到

先执行 `opencli browser safety-education state`，根据当前页面重新获取控件引用。安全教育平台是单页应用，路由切换后旧引用会失效。

### 证书没有下载

成绩页先点击“查看我的证书”，在证书页点击“保存到手机”。检查 Chrome 下载目录和浏览器下载权限。

### 成绩不是 100 分

脚本会报告失败。检查运行记录中的未匹配题目和选项文本，更新题库后再进行平台允许的重考。
